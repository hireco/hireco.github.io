为了给出完整过程，我从安装Node.js开始。  

### 1. 安装Node.js

下载：访问 Node.js 官网，点击左侧的 “长期维护版 (LTS)” 按钮下载 .msi 安装包。  

安装：双击运行安装包，按以下步骤操作：  
  
关键步骤：在安装向导中，务必确保勾选 “Automatically install the necessary tools” 或 “Add to PATH”，这会自动将 Node.js 添加到系统环境变量中。  

其他选项按默认设置，一路点击 Next 即可。  

验证：按下 Win + R，输入 cmd 打开命令行，分别输入以下命令并回车。  


```
node -v
npm -v
```

若看到版本号，即表示安装成功。

为了提高在国内的下载速度，强烈建议安装完 Node.js 和 npm 后，第一时间配置国内镜像源。在终端中执行以下命令即可：  

```
npm config set registry https://registry.npmmirror.com
```

### 2. 安装Claude Code

采用npm安装，命令如下

```
npm install -g @anthropic-ai/claude-code
```

安装完成后，在终端输入以下命令，如果能看到版本号，就说明安装成功了  

```
claude --version
```

如果不知道它安装到哪里了，可以用以下命令查看

```
npm root -g
```

### 3.安装CC-switch

CC-switch是管理Claude Code的大语言模型API的，可以方便切换不同的模型。

访问 CC Switch 在 GitHub 上的官方发布页，下载对应你操作系统的版本：
[https://github.com/farion1231/cc-switch/releases](https://github.com/farion1231/cc-switch/releases)    

按照你的操作系统选择合适版本，我的是Windows，直接点击就可安装。

### 4.安装Warp  

Warp是一个现代化的、自带 AI 功能的终端 (Terminal) 工具。  

访问 [https://warp.dev/download](https://warp.dev/download) 下载 .exe 安装程序，双击运行即可。

### 5.建立Deepseek API

打开DeepSeek开放平台[https://platform.deepseek.com/usage](https://platform.deepseek.com/usage)  

点击左侧导航栏中的“API keys”，然后点击“创建 API key”按钮，随便取一个名字，例如“For Claude”，提交后，自动获得一个API key,由于这个API只会显示一次，请务必复制保存。

### 6.配置CC-switch

双击安装好的CC-switch，看到它当前接入的是Anthropic自己的模型Claude，我们现在要改用Deepseek。于是点击最右侧的+号，在打开的"Claude供应商"中找到Deepseek，选择后，输入之前保存的API Key，一般它会自动填写API请求地址，其他官网和名称啥的可以默认，模型选择“deepseek-v4-pro”，其他默认，点击添加即可。

回到模型列表界面，会发现现在除了Cluade official之外，下面多了一个Deepseek了，先关掉Claude official，再“启用”Deepseek即可。

### 7.使用Claude code

预备工作都配置好了，双击warp图标，打开终端，默认会打开一个终端，可用如下命令查看当前目录

```
pwd
```

一般是C:\Users\{用户名}这个目录，可以在此目录下建立一个子目录作为项目目录，也可以在其他的地方建立，然后通过cd进入此目录。

然后，神奇的一刻来了，输入

```
Claude
```

就会看到Claude的欢迎画面，接下来，你就可以和它对话，命令它为你干活了！
