今天部署一个项目，要求MySQL版本在8.0以上，而现有版本是7.0，只好折腾一下。

基本步骤记录如下：

### 1. 备份数据库

```
cd /MySQL/bin
./mysqldump.exe -u root -p --databases your_database_name > your_database_backup.sql
```
发现需要输入密码，密码不记得了

于是先修改密码

### 2.修改数据库密码


```
./mysqladmin.exe -u root -h localhost -p password "newpwd"
```
改好了，重新回头执行备份，成功。

### 3.停止MySQL服务
我的服务器是IIS的，在cmd下运行

```
net stop MySQL
```
系统提示“服务正在启动或停止中，请稍候片刻后再试一次”

于是启动服务管理器，输入
```
services.msc
```
进入服务管理，发现MySQL服务状态显示“启动”，说明它未处于正常运行状态，于是强制停止，输入命令：
```
taskkill /f /im mysqld.exe
```
返回信息为成功终止进程，并给出PID，回到任务管理器刷新，发现MySQL的状态为空白，表示已成功关闭。

### 4.下载新版本的MySQL

下载新的MySQL版本，下载地址为

[MySQL download](https://dev.mysql.com/downloads/windows/installer/)

### 5.安装过程

下面安装新的MySQL版本，采用全新安装，即安装到一个新目录。

结果安装时发现，提示已有系统，无法升级（因为版本差的太远），只好先卸载，将备份的sql文件拷贝到其他地方，通过控制面板，卸载软件里找到MySQL卸载，然后删除整个MySQL目录的剩余文件。

重新启动安装，这次可以了，选择Custom方式。

点击后，提示有依赖库没有安装，但接下来安装可以自动修复。

<img src="/upload/2026/mysql2.jpg" style="width:400px;300px;">

点击"execute"即可，一路不断下一步，输入管理密码，直到成功安装。

安装完后，会发现C:\Program Files (x86)下有一个MySQL文件夹，在C:\Program Files也有一个，后者才是MySQL服务器系统文件夹，前者只是一个安装文件，可以通过控制面板卸载。

### 6.尝试连接数据库

通过phpMyAdmin连接，结果提示：

```
The server requested authentication method unknown to the client [caching_sha2_password]
```

查询Deepseek,给出配置 my.ini的建议。

发现C:\Program Files\MySQL\MySQL Server 8.0并无my.ini,问Deepseek才知道，配置文件和data都不在这里，而是在C:\ProgramData\MySQL\MySQL Server 8.0下（ProgramData是隐藏文件），遂进入查看。

用记事本打开 my.ini 文件，找到 [mysqld] 这一节，在它下面新加一行：

```
[mysqld]
default_authentication_plugin=mysql_native_password
```

保存文件后，打开 Windows 服务管理器 (services.msc)，找到你的 MySQL 服务（通常是 MySQL80），右键点击并选择“重新启动”。

确认 MySQL 服务处于“正在运行”状态。打开命令提示符（CMD），输入以下命令并回车，然后输入你的 root 密码登录：

```
mysql -u root -p
```

在 mysql> 提示符下，执行下面的 SQL 命令来修改 root 用户的认证方式

```
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '你的密码';
FLUSH PRIVILEGES;
```
这条命令将 root 用户的密码改为你设置的新密码，并将其认证方式设置为 mysql_native_password。如果你是用 root 以外的其他用户名登录，只需把命令中的 'root' 换成你的用户名即可。

完成这两步并确保 MySQL 服务已重启后，再打开 phpMyAdmin，使用 root 用户和刚才设置的密码登录，就成功进入了。

登入后，导入之前备份的数据库文件，至此，MySQL升级安装完成。
